# Grok Voice

一个 Cursor plugin，包含四个 skill，用于在 Grok 上构建语音功能：实时语音到语音、语音到文本听写、文本到语音朗读，以及用于语音会话的 debug 循环。

## 包含内容

- `add-voice`：在应用中构建语音到语音功能，或用其替换 STT-LLM-TTS 级联 / OpenAI Realtime。它会连接实时会话、安全的认证和应用的麦克风；并在输入区添加一个波形图标的语音模式按钮。
- `add-dictation`：语音到文本。批处理模式适用于麦克风按钮或录制的音频（文件、上传、URL），带有词级时间戳、说话人分离和字幕；通过 relay 进行流式处理以获得实时文本。
- `add-read-aloud`：文本到语音。批处理生成 MP3，用于回复上的扬声器按钮；通过 relay 流式传输 PCM，使音频在回复完成前就开始播放。
- `debug-voice`：提出一个计划，以应用自身的语言和约定安装一个仅用于开发环境的日志管道（客户端 logger → 本地 NDJSON），然后运行修复循环：将用户的报告与日志特征匹配，修复一处问题，重新测试。

所有 skill 中的图标约定：波形 = 语音模式，麦克风 = 听写，扬声器 = 朗读。

## 何时使用

当用户要求使用 Grok 为应用添加语音、听写或朗读功能时，当用户运行 `/add-voice`、`/add-dictation`、`/add-read-aloud` 或 `/debug-voice` 时，或者当用户报告语音模式行为异常且需要日志来诊断时，使用本插件。
