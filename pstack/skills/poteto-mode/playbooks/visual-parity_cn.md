### 视觉一致性

**你负责像素级完全一致。基线就是规范。你不要碰它。** 等价性通过图像 diff 验证，而不是靠肉眼。

1. 在任何迁移之前先建立基线：一个视觉回归测试框架，对当前组件在各个状态下截图，在匹配两个实现时还要包含目标。没有基线，就不要声称一致性。这是一个阻塞性的前置条件，不是后续补充。
2. 明确并遵守反捷径条款：不修改测试框架、不篡改基线、不为了使 diff 通过而重组组件。如果基线看起来有问题，停下来询问，不要编辑它。
3. 一次迁移一个组件。跨 worktree 并行，每个组件一个负责人（**separate-before-serializing-shared-state** principle skill）。共享的基础组件先迁移，作为阻塞阶段。
4. 通过 control skill 在匹配界面上用图像 diff 对照基线验证每个组件。非零 diff 即为失败。调查像素差异。对每个组件使用 `/loop`，直到 diff 为零。
5. 按组件或按安全批次运行 **Opening a PR**。

**回复：** 迁移的组件、每个组件的 diff 结果、基线测试框架的位置、剩余工作。
