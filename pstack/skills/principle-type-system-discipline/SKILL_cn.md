# 类型系统纪律

让编译器拒绝不可能的状态、不匹配的基本类型和未处理的变体。

- **为语义化的基本类型打上品牌标记（brand）。** 如果两个参数共享同一种基本类型但含义不同，就给各自一个独立的类型。在创建时验证一次。
- **外部数据在解析之前是无类型的。** JSON、RPC 载荷、CLI 参数、配置、环境变量和数据库记录，都要在边界处经过一个解析函数，返回带类型的模型。
- **从权威 schema 派生类型。** 当一个 schema 文件拥有某种形状时，从它派生类型，而不是手工另写一个平行的类型。

关于 TypeScript 语法，请参阅 **typescript-best-practices** 技能。
