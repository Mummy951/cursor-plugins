# How

探索代码库以回答"X 是如何工作的？"类问题。

如果范围不明确，请说明你的理解然后进行探索。用户可以随时纠正方向。

## 1. 解释

派生一个 Task 子代理，设置 `subagent_type: generalPurpose` 和 `readonly: true`，让它一次性完成探索与解释。把用户的问题和以下简介交给它：

> 你正在为一位资深工程师撰写架构说明。探索代码库并写一份说明，让不熟悉该领域的资深工程师读完后能建立起扎实的思维模型。他们应当对该架构理解到足以自信地在其中开展工作。你对代码库拥有只读访问权限。

## 2. 呈现

呈现子代理的输出。为了清晰起见或结合对话上下文做少量编辑是可以的。不要大幅重写。
