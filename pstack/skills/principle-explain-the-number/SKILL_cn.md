# 解释数字（Explain the Number）

- **在运行之前写下决定。** 指出会改变这个决定的结果，以及噪声底线（noise floor）。当多次运行之间的差异大于效应本身时，就停下来。
- **问「为什么不是两倍？」** 从运行期间获取的性能剖析（profile）或计数器中，指出限制该结果的资源或代码路径。靠读代码猜出来的东西不是限制因素。
- **列出这个数字还可能在测量什么**（错误、被跳过或缓存的工作、从未运行的代码、未调优的一方、噪声、小到无关紧要的部分），并用证据逐一排除。
- **把运行次数、差异和限制因素与数字放在一起保存。**

对于性能数字，运行 [benchmark-checklist](../benchmark-checklist/SKILL.md) skill。对于 eval 结果，要问每一次运行是否都完成了任务、差距是否在多次试验和多个模型中都成立，以及该场景是否重要。
