# 修复根本原因（Fix Root Causes）

修复错误本身，而不是错误浮现出来的地方。根本原因是系统第一次做了不该做的事、或未能处理本应处理的状态的地方。

- 先复现。不断问「为什么」，直到答案指向代码中的一个错误决定。当卡住时，插入检测并读取真实状态。
- 问触发症状的状态是否合法。如果合法，就在代码出错的地方处理它。如果它本不该存在，那么在那里加检查只会把 bug 藏起来，所以要找出产生它的原因。防护、重试、吞掉的错误、被钳制的值和被丢弃的状态，都是隐藏 bug 的常见方式。
- 修复模式，而不是实例。找出每一处存在相同错误的地方。
- 如果那个决定性事实需要深挖才能找到，就提出一个廉价、常开的信号，让它在第一眼就能显现出来。
