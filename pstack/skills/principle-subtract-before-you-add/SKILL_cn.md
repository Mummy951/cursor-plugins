# 先做减法，再做加法

在演进一个系统时，先移除复杂度，再进行构建。默认选择减法。

把简化作为一项持续的投资。让设计在你接手时的相同或更小的表面上，变得稍微更简单、更强大一些。

- 把移除安排在构建之前
- 先裁剪再打磨（在投入质量之前先达到最小化）
- 针对观察到的用法进行设计，而非推测性的边缘情况
- 不添加超出规范要求之外的推测性验证器、解析器或防护代码
- 简化提示词（移除冗余指令、过多的模板）
- 当某处引用没有新内容时，将其删除，而不是留下一个桩
