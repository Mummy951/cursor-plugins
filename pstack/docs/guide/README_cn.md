# pstack 指南

当你不再对智能体事无巨细地指手画脚时，pstack 才能发挥最大作用。你只需描述清楚想要什么，以及怎样才算完成。`/poteto-mode` 会挑选行动手册，按步骤需要调用其他技能，并把证据展示给你看。本指南用贴近实际的提示词帮你养成这个习惯。

你将学到以下内容：

1. [安装 pstack](./01-setup.md)。安装插件并选择模型。
2. [通过 `/poteto-mode` 分派工作](./02-poteto-mode.md)。给它一个目标，看它如何挑选行动手册。
3. [理解代码](./03-understand.md)。先做只读调查，在改动任何代码之前用 `/how`、`/why`、`/teach` 和 `/recall`。
4. [设计变更](./04-design.md)。在代码定型之前，用 `/architect`、`/arena`、`/swarm`、`/interrogate`，以及原型和计划。
5. [构建并清理变更](./05-build-and-clean.md)。构建行动手册、`/tdd`、`/unslop` 和 `/no-comments`。
6. [验证并发布](./06-verify-and-ship.md)。在真实应用上证实行为，正式验证测试很少触及的部分，用 `/benchmark-checklist` 核查数字，然后开一个聚焦于一点的 PR 并推进到合并。
7. [让工作在睡觉时进行](./07-overnight.md)。循环之前先建立信任，一份夜间运行的契约，一份可审查的决策日志，以及能扩展到单个智能体之外的 Projects 和 automations。
8. [用原则名来引导](./08-principles.md)。24 个能在任务中途改变智能体方向的名字。
9. [把它变成你的](./09-make-it-yours.md)。你自己的模式，用 `/correct` 纠正反复出现的错误，以及如何测试技能改动。
10. [用法示例与常见误区](./10-recipes-and-pitfalls.md)。可直接复制的提示词，以及要避开的错误。

第一次请按顺序阅读各页。之后，每一页都可以独立阅读。

当你卡住了，或者不确定该用哪个技能时，输入 [`/poteto-help`](../../skills/poteto-help/SKILL.md) 并附上你的问题：

```text
/poteto-help 我该用哪个技能来评审这个分支？
```

它会给出答案，递给你一条可直接发送的提示词，并链接到答案所依据的技能或指南页面。它不会直接开始干活，因为 pstack 一次运行会消耗真实 token，所以等你准备好再发送那条提示词。它只在你输入时才会运行。

## 如果只记住一件事

用你自己的话，给智能体一个目标，再给它一种检查是否达成的方式：

```text
/poteto-mode 重试发生在运行中途时，导出功能会写出重复行。先复现，再修复并验证。
```

你不需要点名行动手册，也不需要列出技能。「先复现」加上一个可校验的结果，就是 `/poteto-mode` 所需的全部路由信号。它会匹配到缺陷修复行动手册，把步骤复制进待办清单，并在每一步触发时调用相应的技能。
