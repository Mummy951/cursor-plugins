# 我完成了哪些工作

## 触发条件

需要针对特定时间范围（例如：昨天、最近 3 天或上周）内已完成的工作生成一份简短、高信息量的总结。

## 工作流程

1. 将请求的时间窗口解析为具体日期。
2. 读取该时间范围内由当前 git 用户邮箱提交的 commit。
3. 排除 merge commit 和未提交的改动。
4. 将最重要的已交付变更综合成一份简洁的状态更新。
5. 在最终总结中包含实际使用的日期范围。

## 约束准则

- 极其简洁且信息密集。
- 优先关注实质性的行为或架构变更。
- 忽略仅涉及外观的变更（格式、导入、轻微重命名）。
- 不要推断意图或动机。仅从功能层面描述变更。

## 输出

- 一段适合用作状态更新的简短总结
- 实际日期范围
- 可选：2-5 条要点，仅涵盖重大变更
