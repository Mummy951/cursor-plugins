# 创建学习路径

## 触发条件

在多个会话中逐步构建某个主题的能力。

## 工作流程

1. 评估基线知识和目标成果。
2. 将主题从基础到应用实践进行排序。
3. 定义里程碑项目和时间限定的检查点。
4. 添加刻意练习任务以及反馈标准。
5. 回顾进度并调整节奏。

## 工具

- 使用 Ask user tool。

## 护栏

- 让里程碑在既定时间表内可以实现。
- 在每个阶段都包含练习和反思。
- 通过优先精选少量材料来避免资源过载。

## 输出

- 按周或按里程碑划分的计划
- 练习作业
- 进度回顾评分标准
