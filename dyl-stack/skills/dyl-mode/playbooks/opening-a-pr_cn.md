### 创建 PR（Dylan 叠加层）

先阅读共享的操作手册：pstack `poteto-mode/playbooks/opening-a-pr.md`。

然后应用以下关卡。发生冲突时以它们为准。

1. 使用该仓库所用的 PR 托管平台。仓库位于 Origin 时使用 `origin pr`，否则使用 `gh pr`。切勿在两者上同时创建同一分支的 PR。
2. 若这是后续跟进工作，请更新现有的 PR。不要创建重复的 PR。
3. 除非人类在本轮中授权，否则绝不合并或启用自动合并。
4. 创建 PR 不会启动 babysit 看护。发布 URL 后即停止，除非被要求继续。
5. 不要提交临时产物（临时目录、审计输出、本地截图、一次性脚本）。
