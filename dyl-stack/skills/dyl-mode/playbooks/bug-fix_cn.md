### Bug 修复（Dylan 覆盖层）

先阅读共享的 playbook：pstack `poteto-mode/playbooks/bug-fix.md`。

然后应用这些关卡。发生冲突时以这些为准。

1. 在人类使用的同一界面上复现（浏览器或桌面应用使用 `control-ui`，CLI 和 TUI 使用 `control-cli`）。不要跳到理论上的修复。
2. UI 布局、滚动或动画 bug：编码前先测量。捕获前后边界框或一段简短录屏。
3. 在真实应用上验证修复（重新加载、截图或测量）。仅靠单元测试不算完成。
4. 受 flag 控制的界面：确认 flag 关闭路径未发生变化。
5. 在迭代之间保持应用运行，以便人类能够亲自试用。
