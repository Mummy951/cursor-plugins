# Advisor 简报

填写每一部分。证据逐字引用；仅对叙述性内容进行摘要。隐去机密信息。当继续之前的 advisor 咨询时，保留标题，但只写自上次咨询以来的变化，以及新的问题。

```markdown
## 检查点

<重大决策 | 卡住 | 接近完成 | 应请求> — <一行说明为何是现在>

## 用户的请求

<原始请求，逐字引用>

<用户后续提出的约束或更正，逐字引用，按时间顺序>

## 迄今发生的事

<按时间顺序、简明扼要：你调查了什么、决定了什么、修改了什么、尝试了什么、排除了什么，以及每项的原因>

## 证据

<与此检查点相关的逐字工具输出：错误、堆栈跟踪、测试输出、命令输出、相关的 diff 片段。裁去无关的噪音，并用 [...] 标记裁掉的部分>

## 当前状态

<`git status --short` 和 `git diff --stat` 的输出；涉及的文件；任何做到一半的内容>

## 给 advisor 的问题

1. <具体问题>
2. ...

<对于决策：各选项及其你认为的利弊，以及你目前的倾向及理由。
对于卡住：你的预期与实际观察到的对比，以及你已排除的假设。
对于接近完成：你验证了什么、如何验证，以及你未验证的内容。>

## 我需要得到的回复

<例如："一个结论和唯一的最佳下一步"、"确认或反驳假设 2"、"在我宣称完成之前我遗漏的任何内容">

## 完整对话记录

<当本次会话开启 advisor mode 时，取自 `.cursor/advisor/state.json` 的 `transcript_path`；否则为"不可用">
```
